# Scoping without a destination is self-censorship

**Source:** conversation

'Do not use this system for these subjects' is only a control if the excluded thinking has somewhere else to happen. If it does not, the rule degrades into 'do not do that thinking', which defeats the project's entire premise — that thinking happens by writing.

## Additional Context

This is the hinge on which the cheap answer turns. It converts the remaining design question from protection to routing: what is the second place, how much friction does reaching it carry, and does anything need to link to it. A high-friction destination is functionally the same as no destination.
