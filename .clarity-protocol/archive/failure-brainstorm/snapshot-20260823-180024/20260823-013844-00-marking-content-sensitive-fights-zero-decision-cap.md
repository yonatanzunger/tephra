# Marking content sensitive fights zero-decision capture

**Source:** conversation

Any scheme requiring the writer to mark content sensitive before typing collides with the writer persona's defining need — start writing now, no routing decision. The mark gets forgotten precisely when the writer is rushed or upset, which is exactly when the sensitive material is being written.

## Additional Context

The whole design exists because 'which notebook does this go in?' was the friction that killed the predecessor. Re-introducing a mandatory pre-write decision, even a binary one, reopens the wound the subject-tag model closed.
