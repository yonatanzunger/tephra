# A manual irreversible purge is run by one person under stress

**Source:** conversation

Eight hand-run steps, several irreversible, executed at precisely the moment the operator is upset enough to be purging. A wrong pattern removes more than intended or less than intended, with no second person and no dry run. Either the corpus is damaged or the purge silently fails while appearing to succeed.

## Additional Context

The project's notes record three incidents of a tool reporting success while doing nothing: a stale build behind --silent, a typecheck that compiled nothing, a patch script that skipped its target. This procedure has the same shape and higher stakes.
