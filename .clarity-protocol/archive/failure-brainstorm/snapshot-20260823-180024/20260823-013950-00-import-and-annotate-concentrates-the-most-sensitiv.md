# Import and annotate concentrates the most sensitive content

**Source:** conversation

The import-and-annotate flow pairs someone else's politically charged document with the user's unguarded first reactions, timestamped, in a permanent history. It is a machine for producing exactly the material that is most damaging to disclose and most likely to be regretted.
