# OS-level plaintext escapes the corpus and no purge can reach it

**Source:** conversation

Spotlight indexes the notebook, Quick Look caches thumbnails, Time Machine and any cloud backup copy the folder wholesale, and editor swap files persist fragments. Material the user believes purged survives in places the application never controlled and the procedure explicitly cannot reach.

## Additional Context

purge-procedure.md already lists these under 'what a purge cannot reach'. Under a seizure threat model this stops being a caveat and becomes the most likely surviving copy, since Time Machine may itself sync to a third party.
