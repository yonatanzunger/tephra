# Ephemeral content is unfindable months later

**Source:** conversation

If search does not span the ephemeral notebook, the reader persona cannot find anything written there, and working an idea across several sessions means re-finding it by hand each time. If search does span it, ephemeral content enters the durable index and the boundary is decorative.

## Additional Context

There is no free answer. The likely resolution is that search is per-notebook and the ephemeral one is small enough to scan, but that caps how long-running a piece of thinking it can support — which is a real limit on the use case it exists for.
