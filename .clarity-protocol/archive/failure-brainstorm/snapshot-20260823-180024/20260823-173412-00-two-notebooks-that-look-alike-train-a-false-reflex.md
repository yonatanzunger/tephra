# Two notebooks that look alike train a false reflex

**Source:** conversation

The whole app is built to make the writer stop thinking about saving — autosave, crash recovery, position restore, 'any moment where the user thinks I should save this carefully is a defect'. An ephemeral notebook presenting that same interface inherits the trust while removing the guarantee, and work the writer assumed was safe is gone.

## Additional Context

This is the project's recurring theme in a new place: an instrument that lies about itself. The mitigation is not a warning dialog, which is read once and never again — it is that the ephemeral notebook must be continuously and unmistakably visibly different. D41's theme system is the cheap way to do that, since per-notebook appearance is already a parameter set.
