# Protected content leaks through ordinary references

**Source:** conversation

A note in the protected class is linked from, quoted in, or tagged with the same subject as an ordinary note. Tags span the boundary, filesets point across it, and a branched document carries material out of it. The unprotected side then discloses the existence, subject and often the substance of the protected side.

## Additional Context

Tags are ranges over one stream and filesets reference by anchor name, so nothing in the current format knows about a boundary. Any class distinction has to be enforced by every reference mechanism or it is decorative.
