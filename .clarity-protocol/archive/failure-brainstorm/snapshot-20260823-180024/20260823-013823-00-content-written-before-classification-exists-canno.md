# Content written before classification exists cannot be excluded

**Source:** conversation

A protected class of note introduced at v2a cannot retroactively cover anything written before it. Material already in the history stays there, and the only route out is the purge procedure, which is exactly the mechanism judged inadequate.

## Additional Context

scope.md's own rule: data cannot be backfilled, mechanisms can be deferred. Classification is data. Every day between now and the decision accumulates unclassifiable content.
