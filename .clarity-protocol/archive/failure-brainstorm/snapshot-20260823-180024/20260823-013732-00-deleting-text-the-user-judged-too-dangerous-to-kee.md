# Deleting text the user judged too dangerous to keep does not delete it

**Source:** conversation

The user decides a passage should never have been written and removes it. It stays in the repository permanently, so the one explicit act of risk management the user can perform is silently overridden by the design.

## Additional Context

T10, D32, format-spec all state this. What is new is that under a compelled-disclosure threat model it converts from a hygiene problem into the primary exposure: the content most likely to be deleted is the content most dangerous to retain.
