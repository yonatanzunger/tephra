# Commit reasons quote the text, duplicating sensitive content into metadata

**Source:** conversation

Version reasons carry the first line of what changed, so sensitive wording exists in both blobs and commit messages. A purge that rewrites one and not the other leaves half the material behind, and message rewriting is the step most likely to be skipped or botched.

## Additional Context

Chosen deliberately for recall (milestones.md M1). The recall benefit is real; the cost is that every sensitive passage has two homes instead of one.
